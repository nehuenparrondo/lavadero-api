# reports

Admin ve lavados, ingresos, servicios y rendimiento. Empleado solo resumen propio de jornada sin ingresos del negocio. Límites por calendario local y persistencia UTC.

Rutas → middlewares → controller → service → repository. Validaciones en schema y contratos en types.
