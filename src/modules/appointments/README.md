# appointments

Disponibilidad, cotización, reserva y flujo de trabajo. La fila business_settings se bloquea para serializar operaciones de agenda; control de capacidad por barrido de eventos e intervalos de fin exclusivo. Cliente ve propios, empleado asignados y admin todos.

Rutas → middlewares → controller → service → repository. Validaciones en schema y contratos en types.
Consultá [API.md](../../../API.md) para métodos, permisos, ejemplos y errores.
